# Getting help

For usage questions, reproducible bugs, and feature requests, open an
[issue](https://github.com/elide-dev/trufflecel/issues). Search existing issues
first and include the TruffleCEL version, relevant module, JVM or Native Image
version, platform, and a small expression or code example. Remove secrets and
private data from logs and reproducers.

Start with the [README](README.md), [Bazel guide](docs/BAZEL.md),
[extension reference](docs/EXTENSIONS.md), and [publishing guide](docs/PUBLISHING.md).
For performance reports, include the workload and measurement method described
in the [benchmark guide](docs/BENCHMARKS.md).

Use the [security policy](SECURITY.md) for vulnerabilities and the
[code of conduct](CODE_OF_CONDUCT.md) for community concerns.
Community support is best effort and has no guaranteed response time.
